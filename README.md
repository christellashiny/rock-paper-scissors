# Rock, Paper, Scissors

My Python game where a human plays Rock, Paper, Scissors against the computer.

## How to Play
- Enter 0 for Rock.
- Enter 1 for Paper.
- Enter 2 for Scissors.

The computer randomly selects its choice. The program displays whether the result is a win, loss, or draw.

## Concepts Practiced
- Python variables and data types
- User input
- Conditional statements (if, elif, else)
- Random number generation
- Debugging and input validation
